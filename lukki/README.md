# Lukki — сайт бренду

Окремий односторінковий сайт для бренду Lukki (кураторський маркет свідомої моди), зроблений за матеріалами фірмового стилю. Мова сайту — англійська.

**Що всередині**
- 3D-логотип Lukki (витягнутий з вектора), який «тече» й тягнеться до курсора; клік — желейний поштовх.
- Жива стіна з патерну: фігури піднімаються під курсором.
- Маніфест, що «зафарбовується» по словах під час прокрутки.
- Горизонтальна прокрутка з перевагами бренду.
- Слогани, що змінюються, і предмети, які пливуть за мишкою.
- Каталог речей з перетягуванням, вікно товару, список бажань, «повідомити про надходження».
- Калькулятор збереженої води.
- Форма «приєднатися»: для покупців і для брендів.

**Файли**: `index.html`, `css/style.css`, `js/app.js` (інтерактив, список речей — масив `GOODS`), `js/lukki3d.js` (3D), `assets/` (логотип, зображення).
3D-бібліотека береться зі спільної папки `../js/vendor/three.min.js`.

Після публікації сайт доступний за адресою `https://<логін>.github.io/mywebsite/lukki/`.
