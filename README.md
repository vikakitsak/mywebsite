# FLORIS — квіткова студія

Сайт квіткової студії (англійською) з 3D-пелюстками: вони кружляють навколо логотипа, збираються у квітку й у серце, коли гортаєш сторінку, і розлітаються від мишки.

## Сторінки
| Файл | Що там |
|---|---|
| `index.html` | Головна: 3D-пелюстки, колекції, галерея фото, «Як це працює», хіти, відгуки, підписка |
| `shop.html` | Каталог: фільтри, пошук, сортування, вибір розміру та листівки |
| `builder.html` | Конструктор букета: палітра (пелюстки на фоні теж змінюють колір), квіти, кількість, упаковка |
| `about.html` | Про студію, цінності, послуги, квіткова підписка |
| `contact.html` | Контакти, форма заявки, питання та відповіді |

Кошик і оформлення замовлення доступні на всіх сторінках.

## Як змінити дані
- **Адреса, телефон, email, графік, Instagram/Telegram** — на початку файлу `js/main.js` (блок `CONFIG`).
- **Букети, ціни та фото** — у файлі `js/data.js`. Фото лежать у `assets/photos/`.
- **Текстури пелюсток** (з ваших 3D-матеріалів) — `js/petal-textures.js`.
- **Отримувати заявки на пошту** — зареєструйтеся на formspree.io, створіть форму і вставте її адресу в `CONFIG.formEndpoint` у `js/main.js`. Поки це поле порожнє, заявки зберігаються лише в браузері відвідувача.
- **Логотип** — `assets/logo.svg` і `assets/logo-white.svg`.

## Як опублікувати (GitHub Pages)
Settings → Pages → Build and deployment → Source: *Deploy from a branch* → оберіть гілку та папку `/ (root)` → Save.
За хвилину сайт буде доступний за адресою `https://<ваш-логін>.github.io/mywebsite/`.

## Технології
Чисті HTML/CSS/JS без збірки. 3D — [three.js](https://threejs.org) (лежить у `js/vendor`).
