# 🎬 YouTube Shorts агенти

Команда ШІ-агентів, яка щодня аналізує тренди і робить готовий англомовний Short:
відео, обкладинку, назву, опис, теги і звіт, чому обрано саме цю тему.

## Як це працює

```
1. Аналітик трендів  → шукає Shorts, які зараз «вистрілюють» у ваших нішах (YouTube API)
2. Аналітик каналу   → дивиться, які ваші відео спрацювали, а які ні
3. Стратег (ШІ)     → вибирає тему і кут подачі на основі даних
4. Сценарист (ШІ)   → хук, сценарій по сценах, назва, опис, теги, текст обкладинки
5. Продюсер          → ШІ-озвучка, кадри з Pexels, динамічні субтитри, монтаж 1080×1920
6. Публікатор (опц.) → завантажує на YouTube як приватне, щоб ви перевірили
```

Запускається **сам щодня** через GitHub Actions. Ваш комп'ютер для цього не потрібен.

## Що ви отримуєте щодня

Папку `output/<дата>_<назва>/`, у якій лежить:

| Файл | Що це |
|---|---|
| `video.mp4` | готовий Short (вертикальний, із субтитрами й озвучкою) |
| `cover.jpg` | обкладинка |
| `upload.txt` | назва, опис, хештеги, теги, закріплений коментар: просто скопіювати |
| `report.md` | **українською**: чому ця тема, що зараз у тренді, висновки по каналу, що перевірити |
| `script.json` | повний сценарій |
| `credits.txt` | посилання на використані кадри Pexels |

**Де забрати:** вкладка **Actions** → останній запуск → унизу блок **Artifacts** → `short-N` (zip).

## Налаштування (один раз, ~20 хв)

### 1. Отримати ключі

| Секрет | Де взяти | Ціна |
|---|---|---|
| `GEMINI_API_KEY` | [aistudio.google.com](https://aistudio.google.com) → увійти через Google → **Get API key** → *Create API key* | безкоштовно |
| `GROQ_API_KEY` *(необов'язково, запасна модель)* | [console.groq.com](https://console.groq.com) → *API Keys* → *Create API Key* | безкоштовно |
| `YOUTUBE_API_KEY` | [console.cloud.google.com](https://console.cloud.google.com) → створити проєкт → *APIs & Services* → *Library* → увімкнути **YouTube Data API v3** → *Credentials* → *Create credentials* → **API key** | безкоштовно |
| `PEXELS_API_KEY` | [pexels.com/api](https://www.pexels.com/api/) → зареєструватися → *Your API Key* | безкоштовно |
| `YOUTUBE_CHANNEL_ID` | YouTube → ваш канал → *Налаштування* → *Розширені налаштування* → **ID каналу** (`UC…`) | — |

**Усе безкоштовно.** Озвучка (голоси Microsoft Edge) безкоштовна, ключ не потрібен.

### 2. Додати ключі в GitHub

Репозиторій → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
Додайте кожен секрет із таблиці вище (назва має збігатися точно).

### 3. Перший запуск

**Actions** → **Make YouTube Short** → **Run workflow**. Через ~5–10 хв відео буде в Artifacts.
Далі агенти запускатимуться щодня самі.

## Налаштування під себе: `config.yaml`

- `videos_per_run`: скільки відео за раз (1–3)
- `niches`: ніші та пошукові запити для аналізу трендів
- `llm.providers`: порядок моделей ШІ. Щоб отримати кращі сценарії, можна додати платний Claude (секрет `ANTHROPIC_API_KEY`)
- `voice.name`: голос (`en-US-GuyNeural`, `en-US-JennyNeural`, `en-US-AriaNeural` …)
- `publish.enabled`: автозавантаження на YouTube

**Фонова музика:** покладіть mp3-файли в `assets/music/`. Безпечне джерело: YouTube Studio → *Аудіобібліотека*.
Без файлів відео буде лише з голосом.

**Своя тема:** *Run workflow* → поле «Своя тема», наприклад `Why octopuses have three hearts`.

## Автозавантаження на YouTube (етап 2, за бажанням)

Для цього потрібні OAuth-ключі (`YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`).
Майте на увазі: поки Google не перевірить ваш проєкт, відео через API завантажуються **лише як приватні**.
Рекомендуємо спершу 2–3 тижні завантажувати вручну і перевіряти кожне відео.

## Поради для монетизації

- **Перевіряйте кожне відео перед публікацією.** Факти зі звіту (розділ «Перевірити») теж.
- **Через 2–3 тижні оберіть одну нішу**, яка показала найкращі результати (стратег підкаже у звіті).
  Канали з однією темою ростуть швидше.
- **Додавайте своє:** правте сценарій, міняйте назву, відповідайте на коментарі.
  YouTube не монетизує масовий одноманітний контент, а ваша участь робить канал «живим».
- Публікуйте регулярно, 1–2 Shorts на день, в один і той самий час.
